# 英语练习（Safari 版）

打开：https://willisdeng.github.io/English-coach/ ，在 Safari 里点 **分享 › 添加到主屏幕**，以后从主屏幕图标打开。

- 这个仓库只有程序，没有任何个人数据。学习进度、单词本、设置都只存在各自手机的浏览器里。
- Gemini API Key 只存在各自手机上，不会上传。
- `feeds.json` 由 GitHub Actions 每 3 小时抓一次新闻（BBC、RNZ、Kiwi Kids News），因为浏览器不能直接读这些网站。
- `mic-test.html` 是录音 + AI 发音纠正的测试页。
